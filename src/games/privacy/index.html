Privacy

Last updated: 2026-09-29

This notice explains what personal data games.khe.ee handles, why, and what your rights are. The site has no advertising and no user accounts, and it does no profiling or tracking for advertising.

Controller and contact

The controller is Kaido Henrik Elias, who runs games.khe.ee as a private person. For questions about your data or to use your rights, write to kaidoelias@gmail.com.

Analytics

If you allow analytics, Cloudflare Web Analytics collects aggregate usage and performance metrics such as visits, page views, top paths, referrers, countries, browser and device types, and page load timing. It sets no cookies and is not used for advertising. You can withdraw your consent at any time with the button below; withdrawing does not affect measurement made before then.

Cookies and bot protection

The games pages set no cookies themselves. Public traffic passes through Cloudflare, whose bot protection, including JavaScript Detections, checks requests to tell people from automated traffic. For this, Cloudflare may set the __cf_bm cookie, which expires after about 30 minutes. Such a security cookie is strictly necessary and needs no consent.

Browser storage

  • The language choice is stored under app_locale, so it carries between the launcher and the games.
  • The analytics choice is stored under khe.analyticsConsent.v1.
  • Smart Games (/study/) stores game state, such as level progress, in the browser. The server never receives it.
  • AI Adventure (/adventure/) stores game settings and state in the browser.
  • All of it stays in your browser's localStorage until you clear it.

AI Adventure

AI Adventure is for adults only (18+).

To write the story, AI Adventure sends what the players enter through this site's server to an AI provider: the group description with any names in it, the place, the detail, the choices and free text of each turn, and your own premise if you write one, together with the game settings.

The text goes to one of these providers:

  • Google (Gemini API, the default). Because the game is run from the EEA, the Gemini API terms apply their paid-service data terms: Google does not use prompts and responses to improve its products, and logs them for a limited period only to detect abuse. Data may be processed in the United States and other countries; Google's data processing addendum relies on the EU-U.S. Data Privacy Framework and Standard Contractual Clauses.
  • Anthropic (Claude, used only if chosen in the game settings). Under its commercial terms, Anthropic does not train models on API content. Anthropic is based in the United States; its data processing addendum relies on Standard Contractual Clauses.

The server does not log what players enter. Its error logs may contain short fragments of the AI's response. To limit usage, it keeps request and token counters per IP address in memory for up to 24 hours.

Tip: entering names or other personal details is not required, and the game works with made-up names too. Enter only what everyone at the table is fine sending to the AI provider.

Hosting, recipients and transfers

  • The site runs on a home server in Estonia. Fonts and scripts are served from it.
  • Public access goes through Cloudflare, Inc. (DNS, tunnel, TLS endpoint, bot protection and, with your consent, analytics). Cloudflare sees request data such as IP address, URL and browser user agent. Cloudflare is based in the United States; the transfer relies on its certification under the EU-U.S. Data Privacy Framework.
  • The server's access and error logs record requests, such as the time, requested address, response status and browser details, and may include the IP address. They are kept centrally for 30 days and then deleted.

Legal bases

  • Analytics: your consent (GDPR Art. 6(1)(a)).
  • Hosting, Cloudflare's security features, server logs and usage limits: legitimate interest in running the site securely, keeping it available and preventing abuse (GDPR Art. 6(1)(f)).
  • AI Adventure: legitimate interest in providing the game that the players start (GDPR Art. 6(1)(f)). Text is sent only when you start or continue a story.

How long data is kept

  • __cf_bm cookie: about 30 minutes.
  • Server logs: 30 days.
  • Usage counters: up to 24 hours, in memory only.
  • AI providers: under their own terms linked above.
  • Browser storage: until you clear it.
  • Analytics: the site owner sees only aggregate statistics in Cloudflare.

Automated decisions

There is no automated decision-making or profiling.

Your rights

You have the right to access your personal data, to have it rectified or erased, to restrict its processing, and to object to processing based on legitimate interest. You can withdraw your analytics consent at any time with the Analytics choices button. To use these rights, write to the contact address above.

You also have the right to lodge a complaint with the Estonian Data Protection Inspectorate (Andmekaitse Inspektsioon, aki.ee).
